# QuietDock

轻量 Windows 桌面 Dock，使用 C++ / Win32 / GDI+ 实现，无需 Electron、WebView 或额外运行环境。

## 功能

- 磨砂圆角底座、悬停放大、名称提示和运行标记。
- 固定应用及可开关的最近栏；非固定运行应用全部保留入口，最左三个在退出后保留。
- 固定栏和最近栏分别支持拖动排序，配置在重启后恢复。
- 右键添加应用或文件；支持大小调整及开机自启。
- 净桌面模式隐藏任务栏和桌面图标，退出恢复；独立守护进程提供异常退出恢复。
- 屏幕空间不足时通过“更多入口”菜单访问。

## 使用

下载 Release 的 QuietDock-Windows-x64.zip，解压后双击 QuietDock.exe。

右键 Dock 打开设置和添加菜单。Ctrl + 滚轮调整大小。Ctrl + Alt + F12 恢复任务栏和桌面图标；右键“恢复桌面并退出”可退出。

上滑图标会结束对应应用进程，可能丢失未保存内容。文件管理器、文档、回收站和设置按对应窗口处理，不结束桌面 Explorer。

用户数据保存在 %LOCALAPPDATA%\QuietDock，固定项、最近项和顺序自动保存。升级时退出旧程序后替换 EXE，不需要删除用户数据。

## 构建

在 Windows 上安装 MSYS2 UCRT64 的 GCC 工具链，然后运行：

```powershell
.\build.ps1
# 自定义编译器路径：
.\build.ps1 -Compiler 'C:\msys64\ucrt64\bin\g++.exe'
```

输出为 release\QuietDock.exe。

## 已验证与限制

已验证六个真实进程连续启动、隐藏窗口和扫描漏项时保留运行入口、退出后保留前三项、顺序保存及重启恢复。已验证文档、回收站和设置的运行标记，以及正常退出恢复任务栏和桌面。

Windows 搜索、输入法、锁屏等系统宿主不会作为最近应用显示。旧式 ApplicationFrameHost 承载应用和受保护进程识别有限。多显示器、混合 DPI 和休眠恢复尚未完成实机覆盖；不保证兼容第三方 Shell。
